# 图电一体化与黄金轨迹采样 (Golden RT Trajectory) 设计规范

## 1. 核心挑战与设计理念
低轨（LEO）卫星移动极快，如果采用传统的等时间步长采样跑射线跟踪（RT），会导致：
1. **算力极大浪费**：大量采样点处于纯视距 (LOS) 的高仰角区，RT 算出的信道衰落特征高度同质化。
2. **边缘特征丢失**：容易错过卫星在建筑物边缘（如 45° 仰角）刚冒头时的“断崖式”多径突变。

因此，提出**“特征几何驱动的非均匀采样（黄金轨迹采样包）”**策略：只抽取极具物理、几何代表性的关键帧（一次过境约 8-10 点）送入第三方引擎计算。

## 2. 黄金采样点提取逻辑 (extractGoldenTrajectory)
在一次过境中，基于连续时间戳推演，通过以下条件过滤：
- **Benchmark (纯净LOS基准)**：最高仰角点。
- **AOS/LOS 极限边缘**：出入场约 15° 仰角点，代表穿透最厚大气层与最大距离衰减。
- **典型城建遮挡阈值**：如 30°、45°、60° 的突变跃变点。
- **波导与遮挡效应**：若已知地面街道走向（如南北向），寻峰提取方位角与街道**平行 (Parallel)**（波导多径极大值）以及**垂直 (Perpendicular)**（屋顶绕射遮挡极大值）的特征点。

## 3. UI 联动与“时空锚定”设计
基于 Web App 架构，实现宏观几何视图（SGP4 轨迹）与微观电磁视图（CIR 多径结构）的强绑定：

- **主从双向绑定**：采用时间戳 (`Timestamp`) 或时间标记 (`TimeLabel`) 作为核心主键。
- **空间可视化 (Skyplot / Map Markers)**：在极坐标与 Ground Track 上，使用特定颜色的节点渲染带有 CIR 数据关联的锚点。
- **动态交互 (Click & Scrub)**：
  - **Click-to-Render**：用户点击天空图上的特定节点，下方的 CIR 图表（时延-功率谱）瞬间重绘，直观展现多径在不同仰角下的变化。
  - **Timeline Scrubber**：加入时间轴滑动或自动播放，展现从低仰角深衰落到高仰角强 LOS 的多径消失过程。
- **指标仪表盘化**：伴随帧的切换，同步展示 RMS 均方根时延扩展、Ricean K-factor 等核心指标，替代干瘪的数字罗列。
