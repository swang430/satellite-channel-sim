# Satellite Channel Simulator (图电一体化星地信道仿真与联动平台)

A web-based tool for predicting satellite orbits, generating trajectory data for Ray Tracing (RT) engines, and visualizing Channel Impulse Response (CIR) data. Built with React and Vite.

## 🚀 Features

*   **SGP4 Orbit Propagation:** Predicts satellite trajectories and ground tracks using two-line element sets (TLE).
*   **Pass Prediction:** Calculates future satellite passes over a specific ground station, highlighting AOS (Acquisition of Signal), TCA (Time of Closest Approach), and LOS (Loss of Signal).
*   **Golden RT Trajectory Export:** Extracts highly critical geometric points (e.g., specific elevation thresholds like 15°, 30°, 45°, 60°, max elevation, and street waveguide alignments) from dense orbit data. Designed to minimize expensive Ray Tracing (HyperRT) computation costs while capturing significant NLOS to LOS transitions.
*   **CIR Data Import & Visualization:** Import ZIP archives containing Ray Tracing simulation results (`.mat` CIR files). 
*   **Master-Detail View (图电一体联动):** Double-binding synchronization between the macroscopic geometric view (Skyplot / Ground Track) and microscopic electromagnetic view (Power Delay Profile / CIR). Click on a spatial marker to instantly render its corresponding CIR frame.
*   **Playback & Scrubber:** Animate the channel's evolution across a simulated pass.

## 📦 Dependencies

The project relies on the following core libraries:
*   **React (v19.2.0)**: UI framework.
*   **Vite (v7.3.1)**: Build tool and development server.
*   **satellite.js (v6.0.2)**: SGP4/SDP4 propagation for calculating satellite positions and look angles.
*   **Chart.js / react-chartjs-2**: Rendering graphs (CIR, SNR timeline, Skyplot, Ground Track).
*   **jszip**: Parsing imported ZIP archives and generating trajectory ZIP exports.
*   **mat-for-js**: Parsing `.mat` files generated by MATLAB / HyperRT engines directly in the browser.

## 🛠 Installation & Setup

Ensure you have Node.js installed (v18+ recommended).

1.  **Clone the repository and enter the directory:**
    ```bash
    git clone https://github.com/swang430/satellite-channel-sim.git
    cd satellite-channel-sim
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Run the development server:**
    ```bash
    npm run dev
    # or
    yarn dev
    ```
    This will start a local server (usually at `http://localhost:5173/`).

4.  **Build for production:**
    ```bash
    npm run build
    ```

## 📖 Basic Workflow

1.  **Select Satellite:** Use the Quick Select dropdown or input a NORAD ID to fetch TLE data.
2.  **Set Ground Station:** Set your Lat, Lon, and Alt.
3.  **Predict Passes:** Click "Predict Passes" to find future passes.
4.  **Export Golden RT Trajectory:** Click "🌟 Export Golden" on a specific pass (or use the main button) to get a lightweight ZIP package containing geometric key points (`trajectory.csv` & `manifest.json`).
5.  **Run Ray Tracing (External):** Feed the CSV data into your HyperRT engine. Put the generated `.mat` files back into the ZIP (or a new ZIP with the manifest).
6.  **Import & Visualize:** Drag and drop the `.mat` ZIP package into the simulator to watch the dynamic channel evolution synced with the satellite's spatial position.
